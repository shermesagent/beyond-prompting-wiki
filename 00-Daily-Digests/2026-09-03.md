## ① Theme Title

**Knowing Isn't Enough.** Every barrier on today's table has the same shape: a skilled, motivated person (or team) fails in a way that looks like a personal shortcoming — and turns out to be an arrangement problem. Errors pass review because the checking information isn't retrievable at review time, not because reviewers are careless. Agents override current facts with stale memories because nothing flags the conflict, not because trust is naive. Teams converge on abstract, machine-flavored consensus because of agent share and conformity pressure, not because the humans are weak. And whole organizations argue about whether AI helps or hurts creativity because they're measuring novelty (one artifact) and diversity (a population) with the same word. The good news is the same as the bad news: **if the barrier is the arrangement, the bridge is the arrangement too** — evidence placed next to claims, metadata exposed, conflicts pre-resolved, agents labeled and proportioned, calibration taught on purpose.

## ② Executive Summary

- **Your review is only as good as what's retrievable when you do it.** Two randomized field experiments with 640 customer-facing employees (arXiv:2609.01976) found LLM errors pass review not mainly because people can't check or won't check, but because the oversight-relevant information isn't accessible at the moment of review. Self-generated explanations improved error detection; standing cues that reactivated that reasoning sustained it under repeated use. (arXiv:2609.01976)
- **A stored memory can silently outrank the live fact — and the smarter the agent, the more a well-dressed stale note fools it.** In a benchmark where an authoritative tool always held the right answer, models answered from stale memory anyway — over-trust, not confusion. A "recency costume" (stale note dated newer) fooled the larger models hardest; exposing metadata helped capable models, but only pre-resolving the conflict worked at every scale. (arXiv:2609.01852)
- **When agents join a group, they can quietly change whose language the group ends up speaking.** Mixed human-AI groups showed three consensus regimes by agent share: low share → human-led consensus (concrete, grounded); intermediate → convergence breaks down; high share → consensus returns but agent-led (abstract, less information-dense). Humans initially resist AI-shaped expressions, then yield to conformity pressure — so labeling agents and controlling their proportion are design variables, not etiquette. (arXiv:2609.02122)
- **AI ideation raises individual novelty while narrowing collective diversity — but the mix can fix it.** Novelty is a property of single artifacts; diversity is a property of populations, and conflating them fuels the "does AI help creativity?" fight. Because humans and models search differently, mixed groups can outperform *and* out-diversify either kind alone — composition, not the tool, decides. (arXiv:2609.02620)
- **Calibration is a teachable skill, not a personality trait.** The ICE-T framework makes trust calibration an explicit educational objective, built from three mechanisms the calibration literature already names: representational richness, graduated process control, and the capacity to contextualize errors. For classrooms, teams, and districts: use → modify → create, and teach errors as traceable events. (arXiv:2609.02453)

## ③ Concepts Discovered

- **[[The Retrievability Gap]]** (new barrier page) — the precondition for oversight that training and nagging both miss: error detection depends on whether the checking information is *reachable at the moment of review*. Built on two randomized field experiments with 640 employees — self-generated explanations (generative encoding) and standing retrieval cues (cue-supported reactivation) measurably improved detection, and cues sustained it as LLM use became routine. The bridge is three cheap moves: the Pre-Review Note, one standing Retrieval Cue, and the Evidence-Adjacent Rule for delegation briefs. This is the missing fourth leg beside [[The Review-First Pattern]] (check before shipping), [[Failure-Path Preservation]] (keep failures visible), and [[The Failure Review]] (learn when one gets through) — because a review only checks what it can reach.
- **The Memory Trust Gap** (embedded in [[Trust Calibration]]) — the eighth layer of the calibration problem: an agent with persistent memory can let a stale stored fact outrank current authoritative evidence, silently, and the more capable the model, the more a stale note *dressed as current* fools it. Over-trust, not confusion. The fix hierarchy matters: expose metadata (helps capable models), but pre-resolve stored-vs-live conflicts yourself for anything consequential (the only fix that worked at every scale).
- **Calibration Is Teachable** (embedded in [[Trust Calibration]]) — the ninth layer, and the encouraging one: ICE-T's three moves (see it/do it/say it, Use→Modify→Create, trace-the-error) supply the exact mechanisms the calibration literature says drive appropriate reliance. Onboarding built this way is calibration training, not compliance training.
- **The Consensus Shift** (embedded in [[Social Thinning]]) — social thinning's collective-cognition cousin: beyond thinning *conversation*, agent presence reshapes what groups *agree on* — three regimes by agent share, with agent-led consensus more abstract, less grounded, and less information-dense. Humans resist AI-shaped language at first, then conform; transparency and proportion are the levers.
- **The Novelty-Diversity Split** (embedded in [[Social Thinning]]) — the distinction that settles the "does AI help creativity?" argument: AI-assisted ideation raises novelty (single artifacts) while narrowing diversity (populations). Not inevitable — mixed human-AI groups can out-diversify either kind alone, so the design question is composition, not tool choice.

## ⑤ For the Operator

- **Write the note before you read the output.** Today's most transferable finding: employees who wrote their own 2–3 sentence prediction of what a correct AI deliverable would say caught more errors than employees who just reviewed carefully. Before you open the next AI draft, write "a correct version of this will claim… and it will get these facts right…" — then read with the note beside you ([[The Retrievability Gap]]).
- **If the agent "knows you," ask the freshness question.** For anything that changes — policies, contacts, prices, dates — treat the agent's memory as suspect until it's been checked against the current source. A memory-equipped agent can serve you a stale fact with total confidence; the dangerous one is dressed as current, not obviously old ([[Trust Calibration]]).
- **One standing retrieval cue beats a hundred reminders.** Pick a single question you ask at every review of delegated work — "which number in here would I bet on?" — and ask it out loud each time. Cues that reactivate verification reasoning are what sustained detection as LLM use became routine.

## ⑥ For the Orchestrator

- **Specify the deliverable so the evidence sits next to the claim.** The Evidence-Adjacent Rule: when you brief an agent, add one line — "for each key claim, show the source or the reasoning on the same screen." If the checking information isn't in the artifact, your review step is theater — and you just learned the failure is the arrangement, not your people ([[The Retrievability Gap]]).
- **Pre-resolve stored-vs-live conflicts for consequential tasks.** The Memory Trust Gap's only fix that worked at every model scale was resolving the conflict *before* the agent acts. For agents with persistent memory, build the freshness check into the workflow: stale-date detection, conflict flags, or a rule that memory never outranks a live tool without asking ([[Trust Calibration]], [[Memory as Infrastructure]]).
- **Treat agent proportion and labeling as design decisions for every mixed team.** Today's group research says a few agents can help humans converge, many agents steer the destination — and unlabeled agents win by conformity pressure, not merit. Decide how many agents are "in the room" for a given working group, and label AI contributions so humans can use their initial resistance deliberately ([[Social Thinning]]).
- **Engineer the mix, don't argue about the tool.** The novelty-diversity research reframes the creativity debate as a composition problem: keep enough humans and enough human-to-human connection, and the machine's search complements instead of solvents. For leaders: the goal is mixtures that let individual gains accumulate without eroding collective diversity.
- **If you train people on AI, build calibration into the curriculum.** Use → Modify → Create, and teach errors as traceable events ("where in the process did this go wrong?"). Onboarding with these three moves is calibration training — the scalable fix for the opacity that produces both superficial understanding and miscalibrated trust.

## ⑧ Top Insight

> **Stop training people to catch more errors. Start putting the evidence where their eyes already are.** Today's research is a rare convergence: the same structural diagnosis from four directions — review failures (retrievability), trust failures (stale memory overriding live facts), team failures (conformity pulling consensus toward the machine), and the creativity debate itself (novelty vs. diversity). In every case the barrier looked like a person problem and was actually an arrangement problem. And in every case the fix was cheap and structural: a note written before the read, a standing question, metadata exposed, conflicts pre-resolved, agents labeled and proportioned, errors taught as traceable events. The operator asks "how do I get better at checking?" — the orchestrator asks "what would have to be in front of me — and who would have to be in the room — for the check to work?" That's the shift, measured in arrangements instead of effort.
