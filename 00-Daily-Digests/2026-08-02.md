## ④ The Two-Layer Pattern

The wiki's canonical shape: **glossary = 30-second orientation, concept page = the full treatment.** The glossary is an on-ramp, not an encyclopedia — someone who hits "capacity dissolution" in a practice page needs a definition and an action, not a duplicate of the paper summary. A full-length glossary entry doesn't just waste bytes; it breaks the graph. Two pages with identical content don't compound, they confuse — and ambiguous links mean readers land on the wrong copy half the time.

The repair has three parts: trim the glossary copy to its actionable core (definition → plain-language story → exercise → related pages), keep the concept page as the deep dive, and cross-link both directions so the two layers reference each other instead of competing. ## ⑤ Deep Synthesis: The Skill-Bank Layer

The weekend synthesis connects the week's threads — memory as infrastructure, failure-path preservation, cognitive fixed cost, the glossary as the compounding layer — into one idea: **skill records are the unit of compounding intelligence.**

FlowEvo (Ren et al., arXiv:2607.21596, July 2026) is a training-free framework where agents compile successful execution traces into reusable skill records that persist across sessions. Three coupled mechanisms:

1. **Workflow-to-skill compilation** — successful traces become callable skill records with admission checks (interface, replay, safety).
2. **Skill-to-workflow feedback** — accumulated skills get retrieved for new problems via execution or context injection.
3. **Skill curation** — a monitoring mechanism suppresses skills that cause negative transfer. The agent learns what *not* to reuse.

The efficiency signature of real learning: **82.8% success on ALFWorld — 23.6 points above the strongest baseline — at less than half the tokens per episode.**

The orchestrator translation: Phase 3 agents set goals. Phase 3.5 agents remember how they achieved them and build on those memories. That's the difference between an agent that executes recipes and an agent that builds a cookbook. And skill curation is failure-path preservation at the agent level — the same mechanism this wiki practices by logging what didn't work (see log.md).

**The meta-point: this wiki is a human skill bank.** Every SOP page is a compiled workflow. Every glossary entry is distilled skill knowledge. log.md is the curation layer. The rotation itself — ingest → digest → distill → cross-link → commit — is workflow-to-skill compilation running weekly. The wiki is not about the practice. The wiki is the practice.
