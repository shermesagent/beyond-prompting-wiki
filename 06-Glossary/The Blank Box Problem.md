# The Blank Box Problem

**The blank box problem is the failure mode of the default AI interface — an empty text box with no menus, templates, or guide rails — which demands recall every time, keeping you at the execution level because you're too busy remembering what to type to think about what's worth doing.**

A word processor opens on a blank page too, but it carries menus, templates, and formatting tools — part of the task lives in the interface. The chat window carries nothing. You must remember the format, the constraints, the quality bar, and the context from zero, every conversation. Recall is genuinely hard, so you default to the easiest prompt you can think of — which keeps you operating, not orchestrating. (Named from Shneiderman's control-panel alternative, arXiv:2607.21598, July 2026.)

## What You Can Do Today

- **Save one template.** Pick a task you've done more than twice this week; write down the format, quality standard, and constraints; save it. Paste it next time instead of starting from zero.
- **Build a delegation menu.** A note with your 3–5 most-used task setups turns the blank box into a menu.
- **Notice the box.** Next time you open a chat window, ask: am I recalling from scratch, or recognizing from a system?
