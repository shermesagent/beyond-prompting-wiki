# Don't Just Trust Your Memory: Evidence-Linked Memory Reduces Memory-Induced Degradation in LLM Agents

Authors: Yukyeong Lee, Yumin Choi, Jinheon Baek, Sung Ju Hwang. Published 2026-11-10. arXiv preprint 2611.14320.

> External memory enables LLM agents to improve from experience by distilling trajectories of past tasks into concise lessons for new tasks. However, memory can also lead to memory-induced degradation, where an agent fails on tasks it would solve without memory, often because it follows a lesson that is incorrect, or misapplies or misreads a valid one.

Abstract excerpt only. The authors describe WikiTrace linking insights to a rationale and original task record; they report improvements on five agent benchmarks. No school or workplace deployment claim.
