# Synthetic TLX: Forecasting Human Workload Using Agent Simulation

Source URL: https://arxiv.org/abs/2609.12273
Publication: arXiv
Date: 2026-09-14

## Summary

Synthetic TLX proposes using agent simulation to forecast human workload before people attempt technology-mediated tasks. It adapts the NASA TLX workload idea into a proactive signal: instead of waiting for users to burn out or get confused, simulate likely burden, then verify against human data.

For Beyond Prompting, the useful idea is not the scoring method itself. It is the habit of predicting workload before deployment. Many AI workflows look efficient from the outside while quietly moving cognitive burden to the human reviewer, approver, or troubleshooter.

## Beyond Prompting Takeaway

Before adding an agent to a workflow, forecast the human burden: how much attention, checking, context-switching, and recovery work will this create? Then run a small human pilot and compare. If the AI saves production time but doubles review stress, the workflow is not mature yet.
