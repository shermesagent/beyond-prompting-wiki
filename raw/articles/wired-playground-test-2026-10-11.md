# Source note: I Made Terrible Games With Google's AI Playground

Boone Ashworth, WIRED, October 11, 2026. First-person test, read directly on October 11. A plain-language game builder generated three playable games in a day. The writer's dinner-party game did not deliver the intended theme and had confusing controls; changes to the shooter fixed some problems while introducing others. Usage limits stopped further iteration; browsing the gallery, he noticed recurring menu and music choices across games. This is a single writer's product experience, not a benchmark of all AI-built software. Practical translation: test the intended audience's actual task and rerun a small regression check after every revision; a working preview and an appealing first result are not acceptance criteria.
