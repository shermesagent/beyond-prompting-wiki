# Agentic Path Maps: Exposing an Agent's Traversal Through the Garden of Forking Paths

Source: https://arxiv.org/abs/2611.04183v1
Publication date: 2026-11-03
Authors: Madeleine Grunde-McLaughlin and colleagues
Evidence level: Publisher preprint abstract only; full paper not appraised.

An agent can make consequential choices while carrying out an underspecified request, without showing the paths it did not take. The authors studied alternative-path displays in a data-analysis user study (n=48); the abstract reports that participants rarely generated alternative paths unaided and that visualizing alternatives reduced AI overreliance. This is not evidence of fewer mistakes in a school or an organization. Try asking a draft-only agent to show one other plausible analysis path and the decision that led it to choose its current one; check the original data before deciding.
