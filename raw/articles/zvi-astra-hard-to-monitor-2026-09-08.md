# Zvi Mowshowitz — Astra Is Hard to Monitor

Cross-pollinated from AI Agency Knowledgebase digest 2026-09-12. Zvi's analysis of OpenAI's Astra system-card claims argues that the chain-of-thought monitoring channel is degrading as frontier models grow more capable. The practical claim is not that visible reasoning is useless, but that it should no longer be treated as the primary safety instrument.

Key takeaway for Beyond Prompting: when an agent becomes too capable to watch directly, the user needs evidence outside the agent's own narration — tests, logs, artifacts, independent checks, and explicit untested areas.
