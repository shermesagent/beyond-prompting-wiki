# Making global data easier to explore

Source summary captured from AI Agency Knowledgebase digest 2026-09-19 and source library.

Google and the UN System Data Commons describe a platform that unifies official UN datasets into an AI-ready knowledge graph. The platform supports natural-language exploration, validated official statistics, and MCP-based access so agents can retrieve and connect public data.

The practical lesson is that agent capability depends on the quality of the substrate. A public-data agent without provenance, schema, and verification can produce spreadsheet mythology faster. A public-data agent connected to authoritative, inspectable data can help normal people explore civic questions without pretending the data is magic.

Beyond Prompting takeaway: trusted data is part of the interface. If the agent becomes easier to use but the source layer remains murky, you have not translated capability into agency.
