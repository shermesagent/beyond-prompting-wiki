# Source note: A Flaw in ChatGPT's Mac App Could Have Let Hackers Grab Sensitive Data
Authors: Lily Hay Newman and Matt Burgess (publisher article metadata). Publisher: WIRED; October 2, 2026. Publisher report read at https://www.wired.com/story/a-flaw-in-chatgpts-mac-app-could-have-let-hackers-grab-sensitive-data/.
Reported incident: Objective-See Foundation researchers described a now-patched vulnerability in the macOS ChatGPT app that could let malicious local code send instructions through a trusted script-interpreter chain and access chat logs and connected capabilities. WIRED reports OpenAI acknowledged the fix in its September 25 change log. This is a reported local exploit path, not evidence that every user's data was accessed or that all agent apps are affected.
Practice translation (editorial inference): before connecting an agent to files, browser sessions or messaging, list the granted access, keep software current, and test that a stopped or revoked agent cannot continue using the connection. Use approved services for sensitive school information.
