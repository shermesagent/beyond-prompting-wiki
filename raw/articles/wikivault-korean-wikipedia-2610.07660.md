# Source note: When the Commons Appropriates a Large Language Model

Inhwa Song, Sohyeon Hwang, Ted Yoo and Manoel Horta Ribeiro; arXiv:2610.07660v1, announced October 7, 2026. Primary cs.HC RSS abstract checked. The researchers studied WikiVault, an LLM-powered editing tool developed within Korean Wikipedia and used mainly for translation, using ten interviews, platform-scale analysis and matched quasi-experimental comparisons. Experienced editors produced longer and more widely viewed articles; their work shifted toward reviewing and importing. The tool also imported English Wikipedia's editorial judgments along with content. This is an observed community-specific pattern, not proof that translation caused better quality or that every wiki would see the same effects. Try: compare one AI-translated public passage with its original and ask which assumptions, omissions or source choices crossed languages unnoticed.
