# Asclepius: An Adaptive Harness for Long-Horizon Clinical Agents

**Source URL:** https://arxiv.org/abs/2609.13543

**Authors:** Yuan, Zhang, Kim, Luo, Rajpurkar

**Date:** 2026-09-11

## Abstract / Extracted Summary

Using a Clinical Environment Simulator where an agent manages an emergency-department shift under time and resource pressure, the authors show that agents can reach correct diagnoses yet fail to deliver complete and timely critical actions. They identify three long-horizon failure modes: instruction-adherence drift, treatment incompleteness, and severity-equity gaps in timeliness. Asclepius adds a self-evolving harness that rewrites the operating manual between shifts from trace feedback, an external clinical skills library, and isolated subagents for patient-queue decisions. On held-out batches, it improves critical-action correctness by 22% while preserving diagnostic accuracy. Practical takeaway: real deployment failures are often execution failures over time, not one-answer failures. The harness around the agent is the real system.
