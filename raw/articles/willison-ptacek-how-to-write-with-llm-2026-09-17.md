# How To Write With An LLM

Source summary captured from AI Agency Knowledgebase digest 2026-09-19 and source library.

Simon Willison highlights Thomas Ptacek's rule for LLM-assisted writing: use the model for proofreading, critique, fact-checking, grammar, ambiguity detection, and thesaurus-like help, but never use a specific phrase the model suggests.

The rule is useful because it is simple enough to remember. It lets a writer benefit from AI without surrendering the voice layer. The model can point at a weak sentence; the human rewrites it.

Beyond Prompting takeaway: a good AI boundary is not anti-AI. It is a way to keep the human contribution visible where it matters.
